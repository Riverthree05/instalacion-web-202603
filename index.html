Implementación de un Sitio Web en la Nube

Proyecto de instalación y despliegue de un sitio web utilizando tecnologías de desarrollo web, control de versiones y servicios en la nube.

Ver características técnicas

Acerca del proyecto

Este sitio web fue desarrollado como parte de la práctica de instalación web. El objetivo es aplicar conocimientos relacionados con desarrollo web, versionamiento de código y despliegue de aplicaciones utilizando servicios de computación en la nube.

Desarrollo Web

El sitio utiliza HTML5, CSS3 y JavaScript para proporcionar una interfaz sencilla, organizada y adaptable a diferentes dispositivos.

Control de versiones

Git permite registrar los cambios realizados durante el desarrollo y utilizar un flujo de trabajo para organizar las diferentes versiones.

Computación en la nube

El proyecto contempla el despliegue de contenido web mediante servicios de infraestructura y alojamiento disponibles en plataformas cloud.
