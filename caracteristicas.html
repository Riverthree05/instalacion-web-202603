Características técnicas

Tecnologías y herramientas consideradas para el desarrollo, versionamiento y despliegue del sitio web.

HTML5

Se utiliza para definir la estructura y el contenido de las páginas que forman el sitio web.

CSS3

Permite definir el diseño visual, distribución, tipografía y adaptación del sitio a diferentes tamaños de pantalla.

JavaScript

Se utiliza para incorporar comportamiento e interactividad en el sitio web.

Git

Sistema de control de versiones utilizado para registrar y administrar los cambios realizados durante el desarrollo.

Azure Static Web Apps

Servicio contemplado para publicar contenido web estático utilizando infraestructura en la nube.

Oracle Cloud Compute

Permite utilizar una máquina virtual en la nube para instalar y ejecutar un servidor web.

Node.js

Entorno utilizado en la práctica de Oracle para ejecutar el servidor web desde una instancia Compute.

SSH

Protocolo utilizado para conectarse de manera remota a la máquina virtual y ejecutar comandos de administración.
