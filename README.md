# Instalación Web

Proyecto desarrollado para la práctica de instalación y despliegue
de un sitio web.

## Descripción

El proyecto consiste en un sitio web informativo desarrollado con
HTML5, CSS3 y JavaScript.

El sitio contiene las siguientes páginas:

- Inicio
- Características técnicas

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Git
- Node.js
- Oracle Cloud Compute
- Azure Static Web Apps

## Control de versiones

El proyecto utiliza Git como sistema de control de versiones.

Se utiliza un flujo de trabajo basado en las ramas:

- main
- develop

La rama develop se utiliza durante el desarrollo y posteriormente
los cambios estables se integran en main.

## Despliegue

El proyecto contempla el uso de servicios en la nube para realizar
el despliegue del sitio web.

Las plataformas consideradas son:

- Azure Static Web Apps
- Oracle Cloud Infrastructure

Para Oracle Cloud se utiliza una instancia Compute con un servidor
Node.js y acceso mediante SSH.
